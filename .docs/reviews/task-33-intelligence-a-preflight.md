## Failure semantics and minimal validation targets

Existing generic `routingLoss`, `verificationLoss` or `rethrowUnexpectedSourceError` cannot be used as a universal skip classifier because some broad source errors conflate malformed references with legitimate withdrawal. Precheck exact identity edges; reuse throwing retained proof; classify only named proven source withdrawal/expiry/redaction as unavailable protected fields. Preserve safe owned/history headers with explicit unavailable markers, no success-shaped empty protected content. Never drop retired/currently unselected declarations merely because current execution cannot use them.
