## Reading the matrix

W = `workspaceId`; A = `accountId` referring to `socialAccounts`; U = personal app-user reference, with the exact role named. Parent-derived ownership means resolve and validate the actual parent before traversing. `A?`/`U?` means optional or null. Global rows must not be indiscriminately removed by tenant erasure. All fingerprints, references, numeric vectors and consent metadata can still be personal/protected data even without text.

**Complete backend export and complete resumable account/workspace erasure are absent for every matrix row.** TASK-69's local settings export/deletion UI is not a backend/component implementation; no `convex/operations/export.ts`, deletion or retention coordinator exists. The route column identifies an existing bounded discovery index or local cleanup primitive, not a delivered whole-domain export. Existing UI `take`/latest-page limits are never a complete export. A prefix-compatible W index can enumerate a workspace; a compound W,A index can enumerate an account. See the exact schema-index appendix; indexes without a W/A prefix are explicit traversal gaps.

R1 = protected source-copy scrub: `research/contentCleanup.version/evidence/draftCopies/comments`, indexed 25/50-row callbacks, plus `ai/contentCopies.sweep` paginated 25-row ancestry traversal and `ai/runs.purgeSource`. R2 = style scrub: `ai/styleProfiles.sweep` indexed one-row proof pages, `purge` indexed 25-row propagation, `purgeRuns/sweepRuns` followed by R1. R3 = research source/evidence/pipeline cleanup: exact-ID scheduled expiry, indexed source/material/state continuations, `research/pipeline.purge`, actual Agent/Workflow receipts. R4 = assessment scrub: `intelligence/assessments.purgeVersion` indexed 50 rows with repeat, sweep 25-row pages and request sweep. R5 = metric/history removal: `performance/snapshots.clear/expire` and `performance/history.clear/expire`. R6 = calibration removal: purpose redaction, `calibration.clear/sweep`, `models.clear/sweep` and publication projection/pointer cleanup. These preserve permitted finance/publishing parents; they do not implement identity/audit retention.
