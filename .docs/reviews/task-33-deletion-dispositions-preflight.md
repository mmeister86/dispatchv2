These avoid deleting roots before discovering children. Existing workspace-leading indexes already suffice for every other owned family, including aiAttempts.by_native_legacy_intent(workspaceId,accountId,operation,intentVersion,state); it can enumerate all union variants by workspace prefix, so a duplicate aiAttempts workspace index is unnecessary.

`researchCopyBindings` and `researchSourceBindings` have no workspace field. Retain evidence/source/order IDs until indexed children drain; for pre-existing rootless edges use a bounded global pass keyed against the durable deleted-parent manifest. A new optional workspaceId + backfill is an alternative, not a prerequisite if that fallback exists. `githubDeliveryGuids.by_receiptId[receiptId]` is useful for global receipt retention. `xBindings` can be reached by socialAccounts.providerIdentity before account roots are deleted; optional by_workspaceId improves rootless cleanup. Exact pending invitation-recipient cleanup can use new by_email[email] or bounded global pass.

## Installed component cleanup: exact findings

Inspected installed source; no API calls or deployed state were executed.

- Agent `src/component/threads.ts` deleteAllForThreadIdAsync traverses messages and streams only; native completion is real but does not cover memories/orphan vectors. `src/component/schema.ts` memories has threadId/userId/embeddingId indexes; rg over installed src finds memories only in schema and vector comments, so there is no supported memories read/delete endpoint in this installed package.
- Agent `vector/index.ts` DOES expose `deleteBatchForThread({vectorDimension,model,threadId,cursor?,limit})`, but its handler hardcodes table discriminators `thread` and `memory`. ## Retention and minimal tombstones

Operational30days applies to terminal protected data/assessments/cache/usage/eval metadata, clamped earlier by original source/purpose expiration. Debug raw responses remain absent/default off. Do not renew horizons on retry/restore. Ordinary user-authored shared drafts are user data, not automatically a30day transient cache; account deletion must honor shared ownership while removing personal references and invalid protected source material.

Indefinite-until-reconciled exceptions are content-free: aiAttempts/budget original liability tuples; schedules/xPostAttempts/xMediaCheckpoints original unknown send/effect tuple; team invitation unknown email-effect dedupe; R2 namespace/key cleanup receipt while late PUT remains possible. Security suppression barriers/provider-source identity tombstones survive restore/replay as necessary; payloads do not. The user did not authorize manufacturing legal retention reasons.
