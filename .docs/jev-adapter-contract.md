## Deadlines, retries and circuit

Composer 2500 ms and background 5000 ms are startup hypotheses, not benchmarks. Account controls can lower these bounds. The request also carries an absolute deadline, never more than 5000 ms away. Source/payload checks precede a single awaited funding mutation which rechecks current authority and exact fingerprint. After funding, an expired deadline prevents HTTP entirely and preserves an unresolved hold. Only then does the SDK run with both abort signal and remaining deadline; one transport invocation is permitted, redirects are rejected, response bodies are capped at 64000 bytes.

Mandatory Convex database transactions are awaited and cannot be cancelled. Their overhead may exceed the provider deadline; this is not a guaranteed end-to-end UI latency. No physical call starts after the absolute deadline. There are **zero automatic retries**, including 429/5xx/timeout; the maximum-one-retry criterion is an upper bound, not a requirement to replay. A distinct later known-safe operation requires current admission and a newly funded receipt. Sent/unknown attempts for the same exact draft version block further funding.

Three provider/timeout/rate/invalid-response failures open the account circuit for 30000 ms. After cooldown, funding claims one recovery probe atomically; concurrent admissions are denied. Success/low-confidence resets the circuit. Probe failure reopens it. A crashed probe remains denied until explicit operator reconciliation/reset; there is no automatic unsafe replay or fabricated recovery. Each receipt affects the circuit once, even if financial usage is reconciled later.

Timeout races return only after awaiting the unknown settlement. Pending SDK promises contain no Convex writes; a late body after Action return cannot persist results or usage. Unknown liability remains. A genuinely authoritative later usage receipt can be passed to strict internal `settle`; there is no public reconciliation command or background durability claim.

## Runtime response contract and money

Choice and score have separate finite confidence in [0,1]. Confidence >=0.7 is an uncalibrated startup threshold. Choice requires the exact requested label set. Score requires exact ordered rubric keys/descriptions and fractional score within 0..N-1; normalization divides by N-1 without clamping or intermediate rounding. Noul has only a finite [0,1] probability; no confidence is invented. Missing/extra/wrong-shape/nonfinite/out-of-range answers or unsupported model are invalid. Probability maps must match their labels/rubric and sum to one within numerical tolerance. Invalid response, low confidence, provider error, rate limit and timeout remain distinct outcomes; no failed result becomes an aggregate.

All attempts extend the existing **single `aiAttempts` union** with owner `jev-analyzer`, provider `typesafe`, purpose `analyzer` and operation `systemone`. They never impersonate Agent generation/native search. Exact provider/workspace/account analyzer grants use existing `aiBudgets`; `changeLiability` remains the sole shared counter writer. Each funded physical attempt reserves its approved maximum input cost before I/O. Known token usage settles once using integer BigInt ceil arithmetic; duplicate known receipts cannot double-charge and conflicting known receipts fail. Known overage is charged rather than hidden and exhausts subsequent admission. Unknown usage retains the whole hold; no zero-cost forgiveness or timeout retry.

Immutable receipt ownership, policy/price fingerprint and exact budget scope/key/currency are checked independently of current permissions for late settlement. Expired/revoked grants, disabled flags, changed source or retired profile do not erase genuine liabilities. Policy snapshots, referenced budget identities and unresolved receipt IDs must be retained by later lifecycle/operations work. Estimates are not provider invoices: `billedMicros` stays null without an actual currency bill. Receipts store operation, request/profile/version IDs, model/resolved model, question/normalization/price versions, latency, outcome, usage and fallback only, with no draft/prompt copy.
