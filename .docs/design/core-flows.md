# UI-Kernabläufe

1. Demo starten oder Onboarding durchlaufen: Workspace, Zielgruppe und Sprache setzen; Account-Verbindung simulieren; GitHub ist optional. Zur Übersicht wechseln.
2. Signal/Research öffnen → Quellen und Unsicherheit ansehen → Idee speichern → Entwurf erstellen. Wiederholte Übergabe erzeugt keinen weiteren Entwurf.
3. Composer: Einzelpost/Thread bearbeiten, Medien mit Alttext anfügen, Versionsvergleich prüfen, konkrete Version für konkreten Account freigeben. Jede inhaltliche Bearbeitung benötigt erneute Freigabe.
4. Mock-Analyse anzeigen → maximal drei Empfehlungen prüfen → Diff bewusst übernehmen → neue ungeprüfte Version. Bereits geplanter Snapshot bleibt bestehen.
5. Planvorschläge prüfen, einzelne Entwürfe freigeben und Slots annehmen. Nur ausgewählte Vorschläge erscheinen im Kalender. Vergangene/unklare Zeitpunkte und Konflikte werden sichtbar abgewiesen.
6. Kalender Woche/Monat/Agenda: filtern, Zeitpunkt ausdrücklich ändern, Termin stornieren. Fehler, Teilthread und unbekanntes Ergebnis erhalten unterschiedliche Aktionen.
7. Team: Rolle wechseln, Version kommentieren, Reviewer-Zuweisung und Review-Status prüfen. Kommentare freigeben keinen Inhalt.
8. Einstellungen: Integrationen und Capabilities simulieren, Research-Profil/Strategie/Usage/Billing/Benachrichtigungen/Datenkontrollen/Automationsregeln bearbeiten.

## Zustandsmatrix

| Oberfläche | Leer | Laden/Arbeit | Teil/Unsicher | Fehler/Rechte | Wiederaufnahme |
|---|---|---|---|---|---|
| Composer | Neuer Entwurf | Lokales Speichern/Mock-Analyse | Fehlende Score-Dimension | Zeichenlimit, nicht verbundener Account, Viewer | Version wählen, erneut speichern |
| Recherche | Filter ohne Treffer | Simulierter Run | Quellenausfall, Budgetende, veraltete Evidenz | Feste Fehlerdemonstration | Neuer Mock-Lauf |
| Agent | Neue Konversation | Feste Antwort mit Run-Schritten | Vorschlag statt Aktion | Abbruch/Fehler demonstrierbar | Lokaler Verlauf, erneuter Versuch |
| Kalender | Freie Woche | Terminannahme | Teilthread, unklarer Ausgang | Konflikt, Account-Reauth | Abgleich vor Fortsetzung |
| Medien | Keine Treffer | Dateiverarbeitung | Fehlender Alttext | Typ-/Größenfehler | Erneut Datei auswählen |
| Team/Betrieb | Kein Review | Simulierte Aktion | Ausstehende Review-Stufe | Rollenbeschränkung | Rolle ändern/Fehler abgleichen |

Spätere Team-/Multi-Channel-Ansichten folgen denselben Versions-, Account-, Rechte-, Status- und Tastaturregeln. Öffentliche Produkt- und Rechtshinweise sind ausdrücklich Demo-Texte, keine geprüften kommerziellen Veröffentlichungen.
